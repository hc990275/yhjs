## 🛠️ 安装教程

### 第一步：安装 Tampermonkey 浏览器扩展

Tampermonkey 是运行油猴脚本的必备扩展。

| 浏览器 | 安装地址 |
|--------|----------|
| Chrome | [Chrome 网上应用店](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo) |
| Edge | [Edge 外接程序](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd) |
| Firefox | [Firefox 附加组件](https://addons.mozilla.org/firefox/addon/tampermonkey/) |

> 如果 Chrome 网上应用店无法访问，可搜索"Tampermonkey 离线安装"获取 `.crx` 文件手动安装。

### 第二步：安装本脚本

1. 点击浏览器右上角 Tampermonkey 图标 → **管理面板**
2. 点击右上角 **+** 号（创建新脚本）
3. **全选并删除**编辑器中的默认内容
4. 将 `yh.js` 的**全部内容**粘贴进去
5. 按 **Ctrl+S** 保存
6. 刷新任意 YouTube 页面，右侧出现红色下载按钮即安装成功 ✅

### 第三步：安装下载功能依赖

下载功能通过复制 `yt-dlp` 命令到剪贴板，再在终端执行来实现。需要以下依赖：

#### 1. 安装 yt-dlp（核心下载工具）

**方法 A — 通过 winget 安装（推荐 Windows 用户）**

```powershell
winget install yt-dlp
```

**方法 B — 通过 pip 安装**

```powershell
pip install yt-dlp
```

**方法 C — 手动下载**

从 [yt-dlp 官方发布页](https://github.com/yt-dlp/yt-dlp/releases/latest) 下载 `yt-dlp.exe`，放到系统 PATH 目录中（如 `C:\Windows`）。

验证安装：

```powershell
yt-dlp --version
```

#### 2. 安装 FFmpeg（视频合并工具）

yt-dlp 下载的视频和音频是分开的，需要 FFmpeg 合并为 mp4 文件。

**方法 A — 通过 winget 安装**

```powershell
winget install Gyan.FFmpeg
```

**方法 B — 手动安装**

1. 前往 [FFmpeg 官网](https://ffmpeg.org/download.html) 或 [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) 下载 Windows 版
2. 解压后将 `bin` 文件夹路径添加到系统环境变量 `PATH` 中
3. 重启终端

验证安装：

```powershell
ffmpeg -version
```

#### 3. 代理软件（可选）

如果使用代理下载（脚本默认开启代理模式），需确保本地代理软件已运行且监听在配置的端口。

- 默认代理地址：`http://127.0.0.1:30000`
- 可通过 Tampermonkey 菜单 → **设置代理地址** 修改
- 如不需要代理，通过菜单关闭 **使用代理下载** 即可

## 📥 下载功能使用方法

### 操作步骤

1. 打开任意 YouTube 视频页面
2. 点击页面**右侧红色下载按钮** ⬇️
3. **第一步：选择画质** — 弹出画质选择菜单
4. **第二步：选择线程** — 选定画质后自动切换到线程选择
5. 命令自动复制到剪贴板
6. 打开 **PowerShell** 终端（Win+X → Windows PowerShell）
7. **右键粘贴**命令并按回车执行
8. 视频将下载到**桌面**

### 画质档位说明

| 选项 | 最大分辨率 | 说明 |
|------|-----------|------|
| 🏆 **最高画质** | 无限制 | 自动选择视频可用的最佳分辨率（推荐） |
| 📺 **8K (4320p)** | 7680×4320 | 超高清 8K，需视频源支持 |
| 📺 **4K (2160p)** | 3840×2160 | 超高清 4K，主流高清视频 |
| 📺 **2K (1440p)** | 2560×1440 | 准高清 2K，平衡画质与体积 |
| 📺 **1080p** | 1920×1080 | 全高清，最通用的画质 |
| 📺 **720p** | 1280×720 | 高清，体积最小省流量 |

> **💡 提示**：脚本会自动记住你上次选择的画质偏好，下次打开时以 ⭐ 标记高亮显示。如果选择的画质高于视频源的实际最高画质，yt-dlp 会**自动降级**到视频可用的最高画质。

### 三种下载模式

| 选项 | 线程数 | 适用场景 | 建议 |
|------|--------|----------|------|
| 🎬 **单线程下载** | 1 | 长视频（几百MB ~ 数GB） | ⭐ **长视频首选** |
| ⚡ **4线程下载** | 4 | 中等长度视频 | 速度与稳定性均衡 |
| 🚀 **16线程下载** | 16 | 短视频（几十MB以内） | ⚠️ 长视频可能限流失败 |

> **⚠️ 重要提示**：下载长视频（几百MB以上）请务必选择 **单线程下载**。YouTube 会检测多线程并发连接，长视频使用多线程很可能触发限流导致下载失败。

### 下载命令内置优化参数

| 参数 | 作用 | 说明 |
|------|------|------|
| `-c` | 断点续传 | 下载中断后，再次执行同一命令可从断点继续 |
| `--retries infinite` | 无限重试 | 网络波动时自动重试，不会中断下载 |
| `--fragment-retries infinite` | 分片无限重试 | 单个视频分片失败时无限重试 |
| `--throttled-rate 100K` | 限速保护 | 检测到被限速后自动切换到未限速的格式 |
| `--buffer-size 16K` | 缓冲区优化 | 优化数据读取缓冲区 |
| `--http-chunk-size 10M` | 分块传输 | 大文件分块下载，提升传输稳定性 |
| `--write-info-json` | 保存元信息 | 生成 `.info.json` 文件，记录视频元数据 |
| `--skip-unavailable-fragments` | 跳过坏片 | 遇到不可用的分片时跳过，避免卡死 |
| `--socket-timeout 60` | 超时设置 | 单次连接超时 60 秒 |
| `--merge-output-format mp4` | 输出 MP4 | 合并后输出为通用 mp4 格式 |

### 下载异常排查

| 问题 | 解决方案 |
|------|----------|
| 提示 `yt-dlp` 不是命令 | 未安装 yt-dlp，参见上方安装步骤 |
| 提示 `ffmpeg` 错误 | 未安装 FFmpeg 或未加入 PATH |
| 下载到一半中断 | 再次粘贴执行相同命令即可续传（`-c` 参数） |
| 下载速度极慢 | `--throttled-rate` 会自动处理；也可切换单线程 |
| 长视频下载失败 | 切换为 **单线程下载** 模式 |
| 代理连接失败 | 检查代理软件是否运行，或关闭代理开关 |
| 想查看详细信息 | 查看桌面生成的 `.info.json` 文件 |
| 选了8K但实际不是8K | 正常现象，视频源不支持时自动降级到最高可用画质 |
